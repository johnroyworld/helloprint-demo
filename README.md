# Print Marketplace Demo (Vue 3)
A lightweight frontend demonstration built for the HelloPrint interview process.

## Tech Stack
- **Framework:** Vue 3 (Composition API)
- **Tooling:** Vite
- **State Management:** Reactive Refs / Computed Properties

## Key Features
- Dynamic product listing for print materials.
- Real-time cart calculation using Vue's computed properties.
- Responsive CSS Grid layout.
